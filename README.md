# New_Zealand_Sales_and_Profit_For_Store_X_Data_Visualization_2023_to_2027
A simple data visualization about sales, profit, cost and quantity of the store "X" chain operational in 5 different regional of New Zealand from 2023-2027. Data enriched and modified from the original Kaggle of "(New Zealand) Power BI Sales and Profit Analysis Dataset [by: anu2701]".
